# Energy Adapter Configuration

The Energy Adapter configuration tool is located in the Zatobox app.

## Setup Steps

### Prerequisites
- Make sure Bluetooth is active on your mobile device
- Ensure the Energy Adapter device is powered on

### Connecting the Energy Adapter

1. Open the Zatobox app
2. Navigate to the Energy Adapter configuration section
3. Scan the QR code on the Energy Adapter device
4. Wait for the connection to establish

### Configuration

After successful connection, you will see the main configuration page where you can:
- Set the **input meter**
- Set the **output slave**

## Troubleshooting

- Ensure Bluetooth is enabled and the device is discoverable
- Verify the Energy Adapter has power
- Make sure you're within Bluetooth range
- Restart the app if the QR code doesn't scan
