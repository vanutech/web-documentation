# Solis

Compatible inverters for the instruction below.

- Solis RHI ( S5-EH1P(3-6)K-L )
- Solis RAI ( S5-EA1P3K-L )

Prerequisite


- **Zatobox one**
- **[Solis inverter cable](https://zatobox.com/product/solis-cable/)**


#### Step 1 - Connect inverter to zatobox one


TBD image of connector on inverter

The inverter connection provides the power so the Zatobox one should immediately start to light up.


#### Step 2 - Add to zatobox

Go to the device tab and push the plus button to add an extra device. Choose Solis rhi/rai from the list.

More information how to add 3rd party devices with the APP [link](/docs/usermanuals/app-info/add-connecteddevice).
